# Chan Quant 产品规格（Independent v0.1）

> 本文件定义产品范围与成功标准；实际交付状态、未完成目标、阻塞和 NO-GO 统一见 [`implementation-roadmap.md`](implementation-roadmap.md)。

## 产品目标

通过市场概况首页和证券搜索选择沪深股票、ETF 或指数候选，为单一标的提供可追溯的结构、趋势状态、候选信号事件研究、假设性长仓组合研究与图形化审计界面，并支持 2–8 个标的的日 K 归一化走势、历史价格、累计收益、最大回撤与独立行情快照比较。固定指数表现页复用同一后端比较合同，直接展示 8 个已核验沪深宽基指数的区间表现。首页可在运行时读取上交所、深交所官方股票列表与新浪逐证券行情，展示 `CN_A_SH_SZ_V1` 沪深 A 股远端涨跌分布、覆盖率与数据质量，并明确标记不可审计和未文档化来源风险。跨市场身份层可审计地表达港股、美股和全球指数的市场、交易所、MIC、币种、时区、日历与 provider symbol，但在取得具体授权和行情合同前不开放对应日 K/Quote。比较组合可从经过身份核验且带成员来源证据的内置板块装载，也可作为版本化自定义板块保存在当前浏览器。首版是研究工具，不提供实盘交易能力。

由于参考界面的原始公式不可获得，Independent v0.1 采用本项目独立、透明、可测试的规则。产品不得把它描述成参考作者策略的复刻，也不得把简化分型和笔算法描述成完整或正统缠论。

## 页面基准

页面以用户提供的 `IMG_6292.PNG`、`IMG_6293.PNG` 与 `IMG_6309.PNG` 为视觉基准，包含：

1. 根地址的市场概况首页，以及 `/search` 完整搜索页，均支持规范代码、六位代码以及股票、ETF 或指数名称；
2. 全局导航与 Dashboard 顶部的标的切换入口；
3. `/methodology` 数据与方法页，包括数据处理链路、当前数据模式、证据与授权边界、结构/确认/执行时间语义、失败行为和项目自有 API 合同；首页 Hero、数据边界卡和 Footer 提供入口，但不把第三方未文档化参数包装为稳定合同；
4. `/compare` 多标的日 K 走势对比页，包括 2–8 个标的选择、可审计板块速选、浏览器本地自定义板块、可选日期范围、归一化曲线、起始价、区间末收盘、上一交易日涨幅、累计收益、最大回撤、覆盖率、逐项失败、独立 Quote 状态与数据风险；
5. `/indices` 固定宽基指数表现页，包括 8 个已核验沪深指数、快捷与自定义日期区间、历史价格、上一交易日涨幅、累计收益、最大回撤、独立 Quote 和逐项失败；
6. 首页沪深 A 股远端市场温度，包括涨、跌、平、不可用、12 个非零涨跌幅分桶、覆盖率、交易日、universe 观测日期、数据源和质量状态；
7. 标的、日期、数据状态与策略版本；
8. 策略状态标签；
9. 买线、卖线、买卖线差、MA57、短长通道、日周均线八张指标卡；
10. 操作结论、过滤原因、指标证据和预留警告区（v0.1 不计算背驰）；
11. 近两年买卖信号 5/10/20 个交易日事件统计；
12. 假设性长仓组合研究，包括资金、整手、费用、滑点、零成交、固定涨跌停、持仓状态、拒绝原因、权益曲线和组合统计；
13. K 线、成交量、买卖线、MA57、分型、笔和信号标记；
14. 信号结构时间、确认时间和最早执行时间的审计信息。

## v0.1 成功标准

- 同一份 API 快照在前端稳定呈现全部页面模块。
- 根地址在未选择标的时不请求单标的 Dashboard，完整搜索页保留在 `/search`；名称搜索结果明确展示名称、规范代码、交易所和可确认的 ETF 类型。
- 数据与方法页只描述仓库已有的数据模式和工程合同，明确区分官方公开来源、未文档化来源、用户声明、文件完整性与外部认证；远端失败不得暗示存在未实现的自动供应商回退。
- 标的切换后 URL、Dashboard、K 线、实时行情与证券名称保持一致；旧请求不得回写新标的页面。
- ETF 价格按三位小数展示；ETF 的复权、分红和份额折算风险不得复用股票样本的审计结论。
- 页面数字由后端快照驱动，前端不重复实现策略规则。
- 买卖线差、现价相对指标线、指标预热、通道排除当前根、严格分型和事件执行口径有自动测试。
- 假设组合研究由后端按信号次日开盘的一日有效意图计算，显式记录成交或拒绝、持仓、现金、整手、费用、滑点、固定涨跌停和零成交约束；每个决策继续保留结构、确认和最早执行日期。
- 固定 10% 涨跌停、两位价格舍入、税费和滑点必须显示为 `HYPOTHETICAL_RESEARCH_ASSUMPTIONS`，不得外推为 ST、20%/30%、IPO、ETF、指数或任一真实标的的适用交易制度；零成交也不得单独解释为停牌证明。
- 组合统计必须与原有无成本 5/10/20 日事件研究并列，不能覆盖事件统计，也不能被描述为可实现交易绩效、样本外结果或实盘证据。
- 合成数据在页面中显式标记，不能被误认为真实市场结果。
- CSV 输入的来源与复权声明可审计，错误输入明确失败。
- 可审计历史快照把 manifest、SHA-256、数据范围、复权依据和质量 reason code 暴露给 Dashboard；`as_of` 不改变数据集身份。
- 多标的比较在后端完成共同覆盖窗口、交易日并集、归一化收益、累计收益与最大回撤计算；缺失日保持 `null`，单标的失败不拖垮其他成功序列。
- 跨市场比较按各标的 IANA 时区下的本地常规交易日对齐，保留原始 ISO 币种且不做外汇换算；跨币种和跨时区警告由后端生成。没有获准 Adapter 时，身份可解析但日 K/Quote 必须结构化失败关闭。
- 比较页为成功历史序列每 8 秒发送一次最多八标的批量 Quote 请求；逐项失败、延迟和过期状态不清空其他行情或历史结果，整批失败不回退为多个单标请求，切换组合、页面隐藏和卸载会中止旧批次，盘中价不参与历史比较计算。
- 指数表现页固定使用共享目录中的 8 个沪深宽基身份；日期快捷选项只生成请求区间，所有收益与回撤仍由后端拥有，任一历史或 Quote 失败不清空其他指数卡片。
- 行业/主题内置板块必须固定来源指数、成员日期、选择规则、官方响应与成分文件哈希，并把官方权重前 8 名明确标为观察子集；不能冒充完整行业、完整指数、官方指数走势或加权组合。
- 内置板块的成员来源与证券身份来源必须分别展示；成员版本变化需要重新核验官方同日权重、成分文件和全部规范身份，不能在保留旧版本号时静默换成员。
- 单 CSV 和单快照模式不得伪装成多标的数据源；新浪未文档化日 K 与复权风险必须逐标的展示。
- 所有有效数据前缀中的已确认信号身份保持稳定。
- 市场温度从上交所、深交所官方列表与新浪逐证券行情生成；后端拥有远端读取、日期校验、涨跌分类、12 桶、覆盖率、缓存与质量状态，前端不得复算。
- 市场温度满足 `sum(bins)=advancers+decliners`、`advancers+decliners+unchanged=covered` 和 `covered+unavailable=universe_total`；覆盖不足时不得展示柱状分布。
- 截图展示公式标为 `CONFIRMED_DISPLAY`，独立规则标为 `SELECTED_DRAFT`，缺失能力标为 `UNIMPLEMENTED`。

## 非目标

- 券商连接、自动下单和实盘风控；
- 多标的分时图、交易级盘中全市场扫描与北交所市场温度；
- 参数寻优；
- 对策略盈利能力作任何保证；
- 复刻参考作者未公开的公式或历史成功率；
- 把候选退出信号解释为做空策略；
- 完整缠论中的包含、中枢、背驰与一二三类买卖点；
- 把固定规则的假设组合研究包装成交易所级精确回放、多标的资金配置、可实现组合回测或真实交易绩效。
