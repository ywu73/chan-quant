# 新浪财经候选行情源核验

## 定位

新浪财经的 K 线和实时行情地址目前可以在不提供 Token 的情况下访问，但本项目没有找到相应的公开开发者文档、字段版本、服务等级承诺或再分发授权。因此，代码和界面统一称其为**未文档化匿名端点**，不称为稳定公开 API。

本页记录的是北京时间 **2026-07-31 00:51–00:57** 的有限现场观测，不保证新浪后续保持相同参数、字段、访问策略或可用性。

## 一手端点观测

### K 线端点

一手地址：

```text
https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData
```

Independent v0.1 当前只使用以下参数组合：

```text
symbol=sz000001
scale=240
ma=no
datalen=2000
```

现场观测结果：

| 项目 | 观测 |
|---|---|
| HTTP | `200` |
| Content-Type | `application/json; charset=gbk` |
| Cache-Control | `max-age=10` |
| 基础字段 | `day/open/high/low/close/volume` |
| 数值类型 | 多数以 JSON 字符串返回 |
| 成交额 | 未提供 |
| 复权声明 | 参数、字段和响应头均未提供 |
| 无效代码/粒度 | 可返回 HTTP `200` + JSON `null` |
| 缺少必要参数 | 可返回 HTTP `200` + `__ERROR` 对象 |

`sz000001&scale=240&ma=no&datalen=2000` 现场返回 2000 根日 K，范围为 `2018-05-07` 至 `2026-07-30`。请求 `datalen=10000` 时现场返回 8404 根，范围为 `1991-04-03` 至 `2026-07-30`；这只是单次观测，不能作为固定历史上限合同。

### 实时行情端点

一手地址：

```text
https://hq.sinajs.cn/?list=sz000001
```

现场观测结果：

| 项目 | 观测 |
|---|---|
| 无 Referer | `403 Forbidden` |
| 带新浪财经 Referer 和 User-Agent | 可返回 `200` |
| Content-Type | `application/javascript; charset=GB18030` |
| 返回格式 | `var hq_str_<symbol>="逗号分隔字段";`，不是 JSON |
| 稳定性 | 连续探测中出现过 15–20 秒无响应，稍后恢复 |
| 时间含义 | 行情日期和时间在响应字段内，不能用 HTTP 抓取时间替代 |

该端点当前不进入策略计算。Independent v0.1 是日线收盘研究模型，盘中报价既非必要条件，还可能破坏“收盘确认、下一根开盘执行”的时间契约。

## 使用与授权边界

新浪财经 `robots.txt` 没有为上述 money/hq 端点提供可依赖的开发许可：money 子域现场返回 `404`，finance 主站文件近乎空白。新浪官方[知识产权声明](https://corp.sina.com.cn/chn/copyright.html)对网站内容的复制、镜像和其他使用保留权利，但没有为这两个端点提供具体 API 授权或服务等级说明。

因此本项目只把 K 线端点用于低频、本地、单标的研究烟测：

- 不批量扫描全市场；
- 不发布或再分发行情；
- 不把匿名可访问推导成可商用或永久免费；
- 不把端点可用性描述成新浪承诺；
- 商业化、公开服务或再分发前必须另行取得明确授权并完成法律审查。

以上是工程风险边界，不构成法律意见。

## 项目适配合同

后端 `Sina K-line source` 执行以下固定转换：

```text
000001.SZ -> sz000001
600519.SH -> sh600519
scale = 240
ma = no
datalen = CHAN_QUANT_SINA_DATALEN（默认 2000）
```

输出统一转换为 `MarketBar`：

```text
day -> date
open/high/low/close -> float
volume -> int
amount -> null
adjustment -> unadjusted-observed
```

北京证券交易所代码暂不支持。HTTP 非 200、连接失败、超时和畸形响应视为上游故障；规范代码无数据、无效配置和历史不足视为输入/数据合同错误。

## 复权与完整性审计

本项目在 **2026-07-31** 使用新浪现场响应与明确区分原始 OHLC/调整前收盘价的参考日线进行逐日比对。临时参考 CSV 保存在本机临时目录，不进入 Git。

### 观测结果

| 标的 | 公司行动窗口 | 原始 OHLC 匹配率 | 成交量单位中位比 | 观测分类 |
|---|---:|---:|---:|---|
| `000001.SZ` | `2026-06-12` | `100%` | `100` | `unadjusted_observed` |
| `600519.SH` | `2026-06-26` | `100%` | `100` | `unadjusted_observed` |
| `300750.SZ` | `2026-04-22` | `100%` | `100` | `unadjusted_observed` |

成交量中位比 `100` 表示新浪 `volume` 的现场单位为股，而参考源的 `vol` 单位为手。该结果只适用于上述样本和抓取时点。

交易日完整性使用参考源标记为 `SSE` 的开市日历，对 `2026-01-01` 至 `2026-07-30` 进行核验。三个标的各有 `138` 个新浪日期，对应 `138` 个开市日，未观察到缺失或额外日期。单个股票在其他时段可能停牌，审计工具会分别报告“交易所开市但候选源无记录”和“交易所开市但参考源无记录”，避免把停牌或参考缺口直接误报为新浪缺数。

同一会话内对 `000001.SZ` 连续抓取两次，`2000` 个重叠日期中未观察到 OHLCV 修订。它只能证明短时间响应一致，**不能证明跨日、跨月或未来公司行动发生后历史不会重写**。

更有辨识力的官方公司行动核验使用宁德时代 `2023-04-26` 每 10 股转增 8 股事件。新浪历史序列保留了从 `385.90` 到 `213.00` 的原始除权断层，和公司正式公告推导的理论除权价格 `212.9889` 基本一致。官方公告、推导边界及另两个现金分红样本见 `sina-adjustment-research.md`。

### 可复现审计命令

审计工具读取参考日线 CSV，可选读取交易日历 CSV，并在运行时重新请求新浪：

```bash
cd backend
uv run python -m chan_quant.audit.sina_quality \
  --symbol 000001.SZ \
  --reference-daily /absolute/path/to/reference-daily.csv \
  --calendar /absolute/path/to/trade-calendar.csv
```

参考日线要求：

```text
trade_date|date, open, high, low, close, pre_close, vol|volume
```

日期接受 `YYYYMMDD` 或 `YYYY-MM-DD`。交易日历要求 `cal_date,is_open`。默认把参考成交量乘以 `100` 后与新浪对比，可用 `--reference-volume-multiplier` 修改。报告同时给出原始价格匹配率、价格/成交量差异日期、日期缺口、公司行动证据与观测分类。

### 仍未解除的风险

**已观察到的事实**：上述样本和时点中，新浪 K 线与原始未复权 OHLC 一致；三标的指定窗口内未观察到交易日缺失；同会话快照未观察到历史修订。

**不能确认的事项**：新浪没有为该端点提供公开复权合同、字段版本或 SLA；尚未完成跨月历史修订监控，也没有穷举全部股票、停牌、退市、上市首日和所有参数组合。

因此：

- `instrument.adjustment=unadjusted-observed` 只能解释为证据有界的现场标签；
- 页面必须保留“无固定口径合同”的警告；
- 除权除息造成的机械跳变仍会进入 EMA、Donchian 通道、分型和事件研究；
- 信号和事件统计仍只用于结构审计，不能直接与前复权或后复权序列比较表现；
- 若进入正式回测，应换用经过许可、复权口径明确且具有版本管理的数据源，或在后端实现可审计的复权层。
