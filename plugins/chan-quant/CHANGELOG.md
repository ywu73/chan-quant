# Changelog

Versioned with semantic versioning. A backward-compatible feature increments the minor component (`0.1.0` → `0.2.0`); a compatible bug fix increments the patch component; a breaking Tool or response-contract change increments the major component. Codex cachebusters use a `+codex.<token>` build suffix and do not represent a capability release.
