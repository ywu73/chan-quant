# Chan Quant 产品规格（Independent v0.1）

## 产品目标

通过初始搜索页选择单一沪深股票、ETF 或指数候选，并为该标的提供可追溯的结构、趋势状态、候选信号事件研究与图形化审计界面。首版是研究工具，不提供实盘交易能力。

由于参考界面的原始公式不可获得，Independent v0.1 采用本项目独立、透明、可测试的规则。产品不得把它描述成参考作者策略的复刻，也不得把简化分型和笔算法描述成完整或正统缠论。

## 页面基准

页面以用户提供的 `IMG_6292.PNG` 与 `IMG_6293.PNG` 为视觉基准，包含：

1. 未选择标的时的初始搜索页，支持规范代码、六位代码以及股票、ETF 或指数名称；
2. Dashboard 顶部的标的切换入口；
3. 标的、日期、数据状态与策略版本；
4. 策略状态标签；
5. 买线、卖线、买卖线差、MA57、短长通道、日周均线八张指标卡；
6. 操作结论、过滤原因、指标证据和预留警告区（v0.1 不计算背驰）；
7. 近两年买卖信号 5/10/20 个交易日事件统计；
8. K 线、成交量、买卖线、MA57、分型、笔和信号标记；
9. 信号结构时间、确认时间和最早执行时间的审计信息。

## v0.1 成功标准

- 同一份 API 快照在前端稳定呈现全部页面模块。
- 根地址在未选择标的时不请求 Dashboard 或实时行情，名称搜索结果明确展示名称、规范代码、交易所和可确认的 ETF 类型。
- 标的切换后 URL、Dashboard、K 线、实时行情与证券名称保持一致；旧请求不得回写新标的页面。
- ETF 价格按三位小数展示；ETF 的复权、分红和份额折算风险不得复用股票样本的审计结论。
- 页面数字由后端快照驱动，前端不重复实现策略规则。
- 买卖线差、现价相对指标线、指标预热、通道排除当前根、严格分型和事件执行口径有自动测试。
- 合成数据在页面中显式标记，不能被误认为真实市场结果。
- CSV 输入的来源与复权声明可审计，错误输入明确失败。
- 所有有效数据前缀中的已确认信号身份保持稳定。
- 截图展示公式标为 `CONFIRMED_DISPLAY`，独立规则标为 `SELECTED_DRAFT`，缺失能力标为 `UNIMPLEMENTED`。

## 非目标

- 券商连接、自动下单和实盘风控；
- 实时行情与全市场扫描；
- 参数寻优；
- 对策略盈利能力作任何保证；
- 复刻参考作者未公开的公式或历史成功率；
- 把候选退出信号解释为做空策略；
- 完整缠论中的包含、中枢、背驰与一二三类买卖点；
- 在未加入成本、成交约束和持仓状态前宣称完成组合回测。
