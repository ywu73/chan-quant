# Chan Quant 产品规格（v0.1）

## 产品目标

为单一证券提供可追溯的缠论结构、策略状态、历史信号事件研究与图形化审计界面。首版是研究工具，不提供实盘交易能力。

## 页面基准

页面以用户提供的 `IMG_6292.PNG` 与 `IMG_6293.PNG` 为视觉基准，包含：

1. 标的、日期、数据状态与策略版本；
2. 策略状态标签；
3. 买线、卖线、买卖线差、MA57、短长通道、日周均线八张指标卡；
4. 操作结论、过滤原因、指标证据和背驰警告；
5. 近两年买卖信号 5/10/20 个交易日事件统计；
6. K 线、成交量、买卖线、MA57、分型、笔和信号标记；
7. 信号结构时间、确认时间和最早执行时间的审计信息。

## v0.1 成功标准

- 同一份 API 快照在前端稳定呈现全部页面模块。
- 页面数字由后端快照驱动，前端不重复实现策略规则。
- 买卖线差与现价相对指标线的展示公式有自动测试。
- mock 数据在页面中显式标记，不能被误认为真实市场结果。
- 未确认的策略规则保持 `UNCONFIRMED`，不使用猜测填充。
- 后续结构引擎必须通过时间顺序与前缀稳定性测试。

## 非目标

- 券商连接、自动下单和实盘风控；
- 实时行情与全市场扫描；
- 参数寻优；
- 对策略盈利能力作任何保证；
- 在规则尚未确认时复刻他人的历史成功率。
