# 新浪日 K 复权口径研究记录

## 结论

截至北京时间 **2026-07-31**，现场证据强烈支持 `CN_MarketData.getKLineData` 当前返回**未复权原始价格**：新浪响应保留了宁德时代 `2023-04-26` 高比例转增造成的机械除权断层，且三个近期公司行动窗口与参考源的原始 OHLC 逐日一致。

这不是新浪提供的公开合同。没有找到该端点的开发者文档、字段版本、复权参数说明或 SLA；历史是否跨日、跨月重写也尚未验证。因此应用使用证据有界标签：

```text
adjustment = unadjusted-observed
```

它只表示 **observed unadjusted behavior**，不能解释为新浪承诺长期、全标的、全参数组合都返回不复权数据。

## 基于事实的分析

### 宁德时代转增是最有辨识力的样本

新浪历史响应保留了以下相邻记录：

```text
2023-04-25 close = 385.900
2023-04-26 open  = 213.000
```

正式公告对应每股毛现金红利 `2.52` 元、每一股旧股转增 `0.8` 股，股份倍率为 `1.8`。基于公告比例的审计推导为：

```text
(385.90 - 2.52) / 1.8 = 212.988888...
```

新浪除权日开盘 `213.000` 与理论除权值几乎一致，并且历史序列保留了约 `1.8` 倍股份扩张造成的价格断层。若序列已按同一股本口径进行前复权或后复权，事件两侧通常不应继续保留这种机械断层。

因此，该样本强实证支持“当前历史响应为未复权原始价格”。这段推导是审计分析，不是公告原文，也没有代替交易所最终参考价的最小报价单位取整规则。

### 两个现金分红对照样本

平安银行窗口：

```text
2024-06-13 close = 10.800
每股毛现金红利   = 0.719
简单除息值       = 10.081
2024-06-14 open  = 10.150
```

贵州茅台窗口：

```text
2024-06-18 close = 1521.500
每股毛现金红利   = 30.876
简单除息值       = 1490.624
2024-06-19 open  = 1497.990
```

两个窗口都保留了与正式分红相容的价格下移，但除权日开盘还包含正常隔夜价格发现，因此其复权辨识力低于宁德时代的高比例转增样本。

## 完整性与稳定性边界

程序化核验还得到以下有限结果：

- 在参考源标记为 `SSE` 的 `2026-01-01` 至 `2026-07-30` 开市日窗口内，三个标的各有 `138` 个新浪日期，对应 `138` 个开市日，未观察到缺失或额外日期。
- 同一会话连续抓取 `000001.SZ` 两次，`2000` 个重叠日期中没有观察到 OHLCV 修订、增加或删除。
- 宁德时代公司行动窗口短时间重复请求的响应 SHA-256 均为 `35c2dbdb25bea1581da6ddf4859c8d8f38a32537eb7642f1cb092367cad38fe6`。

这些结果只证明指定标的、窗口和抓取时点的行为。它们不能证明：

- 新浪未来不会改变字段或历史处理方式；
- 跨日、跨月或下一次公司行动后历史不会重写；
- 所有股票、停牌、退市、上市首日和所有参数组合都完整；
- 匿名可访问等同于商业使用、公开服务或再分发授权。

## 工程落点

应用保留以下边界：

- 后端输出 `adjustment=unadjusted-observed`，并同时输出“无固定口径合同”的警告；
- 除权除息形成的机械跳变仍会进入 EMA、Donchian 通道、分型和事件研究；
- 结果仅用于研究审计，不作为交易建议或实时交易表现；
- 进入正式回测前，应改用经过许可、复权口径明确且有版本管理的数据源，或实现可审计的后端复权层；
- 使用 `backend/src/chan_quant/audit/sina_quality.py` 重跑价格、成交量、交易日与快照稳定性检查，原始行情和临时参考数据不提交到 Git。
